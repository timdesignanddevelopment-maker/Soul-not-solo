# API credit request — Soul Not Solo

Subject: Requesting API credit support for a free, mission-driven Bible-guidance app

Hello,

I'm an independent developer building **Soul Not Solo** — a free mobile app
where someone describes a struggle they're going through, in their own
words, typed or spoken, and the app finds a specific, genuinely well-suited
Bible passage for it, along with a short word of encouragement. It also
includes a full Bible reader (all 66 books) and a dedication page — this
project is personal, built in memory of the people who shaped my own faith,
and I want it to stay free for anyone who needs it, with no ads and no
paywall.

The verse-matching is the core of the app, and it runs on the Claude API —
every situation someone types gets sent to Claude to pick a passage and
write the encouragement. That means the app's operating cost scales
directly with how many people it actually helps, which is exactly the
tension I'm hoping to ask about.

Before reaching out, I've already taken the responsible steps I could think
of on my end to keep usage efficient:
- Running on Haiku rather than a larger model, since verse-matching doesn't
  need it
- Caching repeat/near-identical situations so the same request isn't paid
  for twice
- Keeping prompts short and the response format constrained to reduce
  tokens per request

What I'm asking is whether Anthropic has a startup, nonprofit, or
mission-driven credit program this could qualify for — or any other
arrangement — that would let this run sustainably as a free app rather than
becoming something I have to shut down or start charging for once it grows
past what I can personally cover.

Happy to share more detail on usage, projections, or anything else useful.
Thank you for considering it.
